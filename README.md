# PRomda FileShare

PRomda FileShare — прямой обмен файлами между компьютерами без регистрации.

## Разрешения

Разрешение запрашивается только при подключении к библиотеке. На компьютере владельца появляется компактное уведомление слева сверху с кнопками «Разрешить» и «Отклонить».

После «Разрешить» создаётся открытая TCP-сессия. В рамках этой сессии удалённый пользователь может обновлять список и скачивать файлы без повторных запросов. При новом подключении разрешение запрашивается заново.

## Хранилище

Файлы автоматически хранятся в `Документы\FPI`. Их можно добавлять через выбор файлов или Drag & Drop. Сервер публикует только реальные файлы из FPI и проверяет путь перед передачей.

## GitHub Installer

Установщик — bootstrap installer. Он не содержит копию приложения: при установке скачивает актуальный `PRomda.FileShare.exe` из последнего GitHub Release, помещает его в `%LocalAppData%\PRomda\FileShare`, создаёт ярлыки и запускает приложение.

Постоянная ссылка установщика на последний release asset:
`https://github.com/Yuka2241/PRomda-FileShare/releases/latest/download/PRomda-FileShare-Installer.exe`

Постоянная ссылка на приложение:
`https://github.com/Yuka2241/PRomda-FileShare/releases/latest/download/PRomda.FileShare.exe`

## Автоматическая сборка Release

Workflow `.github/workflows/release.yml` запускается при push тега вида `v*`, собирает self-contained `win-x64` EXE, компилирует Inno Setup installer и публикует оба файла в GitHub Release.

Пример:

```text
git tag v1.2.0
git push origin v1.2.0
```

После завершения Actions Release будет содержать:

- `PRomda.FileShare.exe`
- `PRomda-FileShare-Installer.exe`

## Локальная сборка

Требуется .NET 8 SDK. Для Windows можно запустить `BUILD_AND_INSTALL.bat`. Для полноценного installer нужен Inno Setup 6.

## Важно про Интернет

GitHub используется только для распространения самой программы. Пользовательские файлы из `Документы\FPI` на GitHub не загружаются.

Для обмена через Интернет компьютер владельца библиотеки должен быть достижим с компьютера другого пользователя — например, через VPN, проброс порта или другой сетевой транспорт. Код библиотеки сам по себе не обходит NAT/CGNAT.
